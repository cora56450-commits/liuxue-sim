# BGM 清单（可点开试听）

全部来自 Pixabay Music：可商用，放进游戏里卖不用署名；不能把音乐文件单独卖，所以不能做 OST DLC。
下载后把曲名、作者、链接、下载日期记进 `game/assets/bgm/LICENSES.md`。
标了“搜索页”的是 Pixabay 的搜索结果页，点进去可以直接在列表里试听。
