## 四、和同类游戏比：还可以加什么、减什么

上次的对比（`内容差距分析.md`）列的问题，今天解决了一大块：周末地点从一句话变成 88 段、四个攻略对象各多了 5–7 段、大二大三改成按周走。下面是还值得做的。

### 建议加

1. **每个朋友一个专属好处**（参考女神异闻录的"协力者能力"）
   现在朋友的好处都一样（孤独 −1、融入 +0.3）。改成每人一个，玩家会为了某个好处去交某个朋友，交朋友就有了目的：

   | 朋友 | 到"朋友"档以后的好处 |
   |---|---|
   | 陈思琪 | 图书馆学业收益 +20% |
   | 吴桐 | 每月一次火锅：精力 +10、孤独 −5 |
   | 周可欣 | 周五缺课的笔记她会发你（缺课不掉学业） |
   | Jake | 健身房精力恢复 +5 |
   | Giulia | 做饭不再失败（"厨房杀手"tag 的负面效果减半） |
   | Mei | 粤语/英语双语帮忙：一次官方邮件、账单问题自动解决 |
   | Hannah | 小组作业分 +3 |
   | 陈建国 | 中超打九折，生病时送冻饺子 |
   | Sophie | brunch 店咖啡第二杯免费 |
   | 学长（好感≥40） | 代购不收代购费，找房佣金减半 |

2. **春节亲戚盘问**（参考中国式家长的"面子"对决）
   大一大二大三的春节，如果选"回国过"或"视频拜年"，加一个小游戏：七大姑八大姨轮流问"在国外学什么""能找到工作吗""找对象了没""那边的人是不是都很开放"。每题三个回答，选得好"面子"涨。这是这个题材最好笑、玩家共鸣最强的地方，现在还没有。

3. **NPC 生日和送礼**（心跳回忆、星露谷都有）
   上次提过，还没定。每人一个生日、喜欢和讨厌的东西各两样；记得生日加好感，忘了交往中的对象会扣。正好配合"好感是门票，考验是关卡"。

4. **冷落看得见**（心跳回忆的"炸弹"）
   好感每周会掉，但玩家看不到。改成：太久没联系，对方发一条"最近很忙吗？"；再不理，变成"已读"不回。不用新系统，用手机消息就能做。

5. **每年一次的"大场面"**（参考美少女梦工厂的收获祭）
   每年一个全员出场的大活动，把认识的人都放进来：大一中秋晚会、大二时尚社的秀（Ollie/Ploy）、大三毕业展。现在毕业展有了，前两个没有。

### 建议减

1. **朋友分两档写，不要 12 个人都写满**
   12 个朋友全写满四档事件，量很大，而且每局能认识的也就 6–8 个。建议：
   - 主要朋友 6 个（陈思琪、吴桐、Giulia、Mei、Jake、Hannah）：四档事件都写；
   - 次要朋友 6 个（周可欣、陈建国、Sophie、Ben、赵子豪、Marcia）：只写熟人和朋友两档，靠周末小剧情撑。
2. **tag 分支只给影响大的 tag 写专门文本**
   22 个 tag 都写分支写不完。建议只给 8 个最有戏的 tag（厨房杀手、超级大厨、二次元、恋爱脑、天生路痴、家教森严、剁手狂魔、学霸底子）在大事件里写专门台词，其他 tag 只影响数值。（E 人/I 人不是 tag，是开局选项，照旧写分支。）
3. **Essay 学姐的第二次找上门（第 21 周）可以并进周中事件池**，不用单独占一个固定周。

### 不建议加

- 战斗、经营小游戏这类和留学生活关系不大的玩法：火山的女儿、中国式家长都有，但我们的卖点是"真实的留学生活＋恋爱"，加了会散。
- 更多攻略对象：四个已经覆盖了四种类型（同胞学长、本地帅哥、国际生、本地宅男），再加会稀释每条线的深度。
