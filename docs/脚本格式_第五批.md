# 剧本转脚本：第五批新格式（coding 用）

基础写法见 `data/events.js` 顶部注释（say / show / choice / if / fx / run …），这里只写第五批新加的。转完跑：

```
node tools/validate_events.js data/events/你的文件.js
```

## 一、通用规矩

- 一个剧本文件转成一个（或两个）`data/events/*.js`，开头 `Object.assign(DATA.events, { ... });`，登记表用 `.push(...)`。
- **不改别的文件**（index.html、js/、别人的 data 文件都不动）。要引擎支持的东西写进文件末尾的注释 `// 给引擎：…`。
- 正文照抄，不改写、不删句子。英文台词：`say` 写英文，`tr` 写「」里的中文（不带「」）。
- 旁白"你……"直接 `{ say }`；内心（……）照原样带括号写进 `{ say }`。
- `〔好感·Ollie+2〕` → `fx: { aff_local: 2 }`；`〔友情·吴桐+2〕` → `fr_wu_tong`；`〔英语+1〕` → `english: 1`；孤独 `loneliness`、融入 `belonging`、精力 `energy`、学业 `study`、钱 `money`（£ 数）、适应 `adapt`；`〔标记：xxx〕` → `flag_xxx: 1`。
- 计数（剧本里写"计数"的，比如 `ploy_ghostwrite`）：`inc_ploy_ghostwrite: 1`（引擎会 +1）。
- 选项文字只放引号里说的话或动作，**不写数值、不写〔〕**。【如果：…】的选项 → 选项的 `if`。
- 角色 id：senior=学长/林子航，local=Ollie，groupmate=Ploy，otaku=Kieran，其余见 `data/characters.js`。没有 id 的人（Kieran 的妈妈、公交司机……）`name` 直接写中文名牌，比如 `name: "公交司机"`。
- 条件：`标签('二次元')`、`标记('xxx')`、`好感('local') >= 20`、`友情('吴桐') >= 30`、`性格 == 'I'`、`专业 == '设计'`、`住宿 == '学校宿舍'`、`学年 == 2`、`周数 >= 5`、`家乡 == '广东'`、`交往中('local')`、`英语 >= 70`、`物品('heater_key')`。
  - 老家=广东：用 `省份 == '广东'`（引擎会加 `省份`）。
- 【背景：xxx】→ `{ bg: "xxx" }`；新背景 id 能用：kieran_room、ploy_flat、ollie_house、bicester、senior_room、hall_stage、xmas_market、ollie_room、dept_store。
- 【立绘：Ollie·笑】→ `{ show: "local", expr: "smile" }`（表情名见 characters.js 的 expr）；【CG：…告白】→ `{ cg: "senior_confess" | "local_confess" | "groupmate_confess" | "otaku_confess" }`。
- 自由输入【可自由输入：…】→ 在那组 choice 上写 `free: "这段在讲什么（一句话）", freeWho: "local"`（不要另加一个"✎ 自己说"选项，引擎自己加）。
- 每个选项后面要有专属反应（至少一句），剧本里没写反应的，写进文件末尾注释 `// 缺反应：…`，不要自己编。

## 二、手机段落【手机：某人】……【手机收起】

```js
{ phone: "local", time: "周三 23:12", steps: [
  { say: "你好！今天你吃饭了吗？", name: "local" },          // NPC 发的消息
  { say: "我很饿你", name: "local" },
  { choice: [
    { text: "“是'我饿了，你呢？'……”", then: [ { say: "Oh no.", name: "local", tr: "哦不。" } ] },
    { text: "发一条语音，念给他听", store: "[语音 0:12]", then: [ … ] },   // 动作选项：store 写存进聊天记录的那一行
  ] },
  { say: "（他秒回了。）" },                                // 不带 name 的是旁白：演出来，但不存进聊天记录
] }
```

- `phone` 写人物 id；群聊写 `"group:study"`（小组群）、`"group:flat"`（flat 群）、`"group:hometown"`（老乡群）、`"group:family"`（家里群）。群里每条 `name` 写发言人。
- `time` 用剧本写的时间，没写就不写（引擎用"晚上"）。
- 选项默认把 `text` 去掉引号和（）〔〕后存成"我"发的消息；动作选项写 `store`。主角在手机里主动说的话 `{ say: "…", name: "me" }`。
- 朋友圈【手机：朋友圈】：`{ moment: { who: "senior", text: "本周六比斯特", tr: "", img: "一张照片的描述" } }`，一条一个步骤。

## 三、告白的限时选项

```js
{ timed: { text: "先说出口", sec: 8,
  during: [ { say: "I…", name: "local", tr: "我……" }, { say: "（他清了一下嗓子。）" } ],   // 倒计时期间继续打字的台词
  then:    [ { fx: { flag_confess_me_first_local: 1 } }, …主角先说… ],
  timeout: [ { fx: { flag_confess_them_first_local: 1 } }, …对方先说… ] } }
```

只有告白用。原来"谁先说"那组选项里"等他开口"删掉。

## 四、小游戏

```js
{ game: "messy_room", win: [ …玩得好… ], lose: [ …一般… ] }
```

id：`messy_room` 胡闹客厅、`outfit` 穿搭挑战、`packing` 打包代购、`socks` 双人成袜、`monster` 怪物猎手、`fighter` 拳霸97、`bargain` 砍价、`tones` 声调配对、`yellow_sticker` 黄标抢购、`crit` crit 答辩、`relatives` 春节盘问、`cooking` 做饭。还没做的小游戏引擎按"普通结果"走 `lose`（没写 lose 就直接往下）。剧本没分输赢的，只写 `{ game: "id" }`。

## 五、背包物品

- 剧情给东西：`fx: { item_heater_key: 1 }`；用掉/送掉：`item_heater_key: -1`。
- 物品在文件里登记（没登记的会被检查报出来）：

```js
Object.assign(DATA.items = DATA.items || {}, {
  heater_key: { name: "暖气钥匙", desc: "Dave 给的，能开锅炉间", from: "第7周 Dave", gift: false },
});
```

`gift: true` 能送人。物品 id 用英文小写下划线。

## 六、随机挑人 {A} {B} {室友}

剧本里"任意一人""任意两个认识的人""{室友}"：在登记表那一条写 `pick`，文本里照写 `{A}`，说话人 `name: "{A}"`，数值 `fr_{A}`：

```js
DATA.placePool.push({ id: "campus_6", place: "campus", pick: { A: "known", B: "known" } });
// pick 的值："known"＝任意认识的固定 NPC；"roommate"＝室友；或者一个数组 ["giulia","mei","jake"]（从里面挑认识的）
```

## 七、登记表（文件末尾写）

| 表 | 用在哪 | 一条的写法 |
|---|---|---|
| `DATA.loveEvents` | 攻略对象的小事件、扩写事件（周末去某地点碰到时演） | `{ id, who: "local", kind: "small"\|"ext", place: "brunch" 或 ["brunch","campus"], cond: "好感('local') >= 20 && …", small: true }`。`small: true`＝小事件（好感封顶规则，见决定记录第十一节）；原攻略线级别的（推进/告白类）不写 small |
| `DATA.midweek` | 周中插播 | `{ id, day: "tue", time: "晚上", cond: "…", week: 10, year: 1, who: "local", prio: 1, small: true }`。day：mon/tue/wed/thu/fri，没写默认 wed；prio：1＝剧本写死周数的，2＝扩写里条件满足的，3＝周中事件池；week/year 只在写死周数时写 |
| `DATA.placePool` | 周末地点小剧情 | `{ id, place: "dorm_room", people: ["wu_tong"], cond: "住宿 == '学生公寓ensuite'", variants: true, pick: {...} }`。people＝段里出现的固定 NPC（不认识就不抽）；variants＝写了大二/大三变体 |
| `DATA.placeLines` | 地点"一句话"（池子抽空时） | `DATA.placeLines.campus = [ { text, if: "…季节/年级条件" } ]` |
| `DATA.passersby` | 随机路人 | `{ id, where: "road" 或地点 id, cond: "…" }`，正文写成 `DATA.events[id]` |

- 年级变体：在事件里写 `{ if: "学年 >= 2", then: [变体], else: [原文] }`（大二、大三不同就嵌两层）。
- 季节条件：`季节 == '秋'`（引擎会加 `季节`：秋/冬/春/夏）；下雨周：`下雨`；周末哪天：`周末日 == '六'`；时段：`时段 == '晚上'`。
- 已有的 `DATA.encounters`（11 段偶遇）引擎会自动并进 placePool，不用重写。

## 八、大二大三周历

`DATA.calendarY2`、`DATA.calendarY3`，每年 24 条，字段同 `DATA.calendar`（week、term、label、fixed、after、vacation、deadline、exam、rain），另加：
- `trials: [{ who: "senior", if: "…" }]` 这周演恋爱考验；`confess: true` 告白窗口；`spring: true` 春节；`mark: true` 交作业出分；`final: true` 最终提交；`close: true` 这周先算学年总分；`festival: "hall_stage"` 年度大场面。
- 池子周 `{ week: 5, term: "大二·秋", label: "第5周" }` 不写 fixed。
