# 邀约系统（策划，2026-11-17）

Cora 定的：不管是玩家在手机里约别人，还是对方（AI 生成或剧情固定）约玩家，答应了的邀约都要**真的放进玩家的日程**，占掉那个时间，到时候真的去（或者爽约）。

现在游戏里只有周末地图的随机偶遇（`S.weekendDates` 只是记录偶遇过谁），没有真正的约。下面是新系统。

## 一、三种来源

| 来源 | 怎么发生 | 谁能约 |
| --- | --- | --- |
| 玩家约人 | 手机私聊里点“约”按钮 | 好感／友情 ≥20 的人 |
| 对方约玩家（日常） | 每周一开始时系统按概率生成，或 AI 聊天时对方提出 | 攻略对象好感 ≥30、朋友友情 ≥30 |
| 剧情固定邀约 | 篝火节、情人节、春节、Reading week 同行等，剧本里写好的 | 按剧本条件 |

三种来源最后都变成同一种东西：一张**邀约卡**，玩家选“答应／拒绝／改个时间”。答应了就写进日程。

## 二、邀约卡长什么样

车站标识风，做成一张车票：

```
┌────────────────────────────────────┐
│ Ollie Bennett          INVITATION  │
│ 周六 SAT ── 周末行动               │
│ brunch店  ·  2 行动点  ·  约 £18   │
│ “Brunch? My treat this time x”     │
│  「brunch？这次我请」              │
│ [答应 ✓]  [改时间]  [拒绝 ×]       │
└────────────────────────────────────┘
```

卡上写清楚：谁、哪天、哪个时段、去哪、要花几个行动点或占哪个日程格、大概花多少钱。

## 三、时间怎么占

| 约在什么时候 | 占什么 | 去了等于 |
| --- | --- | --- |
| 工作日某一天 | 那一天的日程格，锁定成“和某某·地点” | 这一格的效果按“社交”算，再加上对方的好感／友情 |
| 周末 | 周末地图上对应地点放一个带头像的约会标记，去这个地点要花它的行动点 | 地点效果＋好感／友情，必定碰到对方（不靠 60% 偶遇） |
| 出城（周末整段） | 整个周末 | 出城效果＋同行版的旅行事件 |

- 日程页：被约占掉的格子显示成车票样式“约·Ollie · brunch”，玩家可以点开取消。
- 手机日历 App：所有已答应的邀约按日期列出来。
- 周末地图：有约的地点标记上挂对方的小头像，周末开始时提醒“今天和 Ploy 约了酒吧街”。

## 四、去了、没去、取消

| 情况 | 攻略对象 | 朋友 |
| --- | --- | --- |
| 去了 | 好感 +5，有机会触发约会小事件（AI 生成或固定） | 友情 +4 |
| 提前在手机里说“去不了了”（取消） | 好感 −2 | 友情 −1 |
| 答应了但到时候没去（爽约） | 好感 −8 | 友情 −4 |
| 拒绝邀约 | 日常邀约 −1，节日邀约 −3（已定） | −1 |

- 爽约的判定：工作日那一格被玩家改成别的活动；周末结束时没去那个地点。
- 被锁住的格子要改，会先弹提示：“你和 Ollie 约了周三，确定不去吗？”

## 五、冲突和鱼塘

- 同一个时段只能答应一个邀约；已经有约的时段，新邀约上只显示“这天有约了”和“改个时间”。
- 同一个周末答应了两个攻略对象（不在同一个地点）：照原规则**必定翻车**。答应第二个的时候弹一次提醒：“这个周末你已经约了学长。”玩家坚持就照办。
- 朋友的邀约和攻略对象的邀约同一个周末，不算鱼塘。

## 六、谁会答应、谁有空

**答应的门槛**（玩家约人时）：

| 约什么 | 攻略对象 | 朋友 |
| --- | --- | --- |
| 一起去学校、图书馆、超市 | 好感 ≥20 | 友情 ≥20 |
| 吃饭、brunch、酒吧 | 好感 ≥40 | 友情 ≥30 |
| 单独出城 | 好感 ≥60 | 友情 ≥60 |

不够门槛时对方会婉拒（“这周有点忙”），不扣分。

**固定的忙**（不随机，每个人一张小表）：

| 人 | 什么时候没空 |
| --- | --- |
| 学长 | 周六上午（寄代购） |
| Kieran | 周二、周四晚上（健身房），健身房里可以碰到但不会单独约 |
| 周可欣 | 周末（去伦敦），大二分手后改成有空 |
| 陈思琪 | 考试周、ddl 周 |
| Ben | 经常没空（打两份工），只有约在学校能成 |
| 陈建国 | 只能约在中超，你打工那天 |

**对方主动约你的频率**：每周一开局时，每个够格的人有一次机会。概率 = 好感（或友情）÷ 200，最多 40%；一周最多收到 2 个日常邀约（剧情固定的不算）。

## 七、AI 聊天里的邀约

- 聊天的系统提示词里带上玩家这周的日程（哪天有空、有约）和这个角色的“固定的忙”。
- AI 在对话里想约玩家，或者答应玩家的提议时，在回复末尾附一行机器能读的标记，例如：`[[INVITE day=SAT slot=weekend place=brunch]]`。游戏读到以后弹出邀约卡，**由游戏校验**（时间、地点、门槛、冲突）后才写进日程。AI 自己不能直接改日程。
- 校验不通过（地点没解锁、那天有约、钱不够）：邀约卡上写原因，让玩家改时间或拒绝。
- 没有 API Key 时：玩家点“约”以后从固定选项里选（时间＋地点），对方按第六部分的门槛回复固定文本；对方主动邀约用每个角色的固定台词（策划这边写，一人三五句）。

## 八、大二大三、暑假

- 大二大三浓缩：没有逐周日程，邀约变成每段开头的一张汇总卡：“这段时间 Ollie 约了你几次”，玩家选“都去／去一半／没空”，按次数结算好感，也算进交往中的互动（“没空”对应之前定的“卷、打工没空陪”扣分）。
- 暑假：只有人在同一个地方才能约；不在同一个国家时，邀约变成“视频通话”，只加一半。

## 九、编程要做的

1. 状态：`S.appointments = [{ who, day, slot, place, source, status }]`，存档里带上。
2. 手机私聊加“约”按钮和邀约卡；日历 App 显示已答应的邀约。
3. 日程页：约好的格子锁定显示，可取消（弹确认）。
4. 周末地图：约会地点挂头像标记，去了必定见到对方；周末结束结算爽约。
5. 每周一生成 NPC 邀约（第六部分的概率和上限）。
6. AI 回复里的 `[[INVITE ...]]` 标记解析和校验。
7. 剧情固定邀约（篝火节、情人节、春节等）改成用同一张邀约卡，答应后同样写进日程。
8. 每个角色的“固定的忙”放进 `data/characters.js`。

邀约卡上的台词、没 key 时的固定邀约台词，策划这边写。
