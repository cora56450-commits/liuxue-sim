# 开局 tag 效果细则（策划，2026-11-17）

每个 tag 分三部分写：**数值**（编程照着实现）、**剧情**（剧本里怎么分支）、**AI**（传给聊天和小红书的一句话）。

几条总规则：
- 能固定的就固定，少用概率。
- 剧本里写成【如果：tag名】，例如【如果：厨房杀手】。每个 tag 在大一至少要有 2 处剧情分支，不然玩家感觉不到。
- 数值一栏标「已实现」的是框架里已经有的，「新增」「改」是要编程做的。
- 原表里的“心情”“压力”游戏里没有这两个数，下面统一换成孤独、精力。
