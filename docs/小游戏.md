# 内置小游戏（2026-11-18，Cora 提）

原则：
- **CSS/HTML 就能做**，美术只要一张 GPT 生成的图标表（透明底，一张图上画几十个小物件，程序切开用）。
- 每个 30–90 秒，规则一句话说得清。
- **都能跳过**：开始前有"直接跳过（按普通结果算）"按钮；设置里可以"小游戏全部自动通过"。
- 奖励小：好感/友情 +1～+3、钱、精力，不影响结局走向。玩得好有一句专属台词。
- 第一次玩时，INFO 问讯处小卡讲规则。
