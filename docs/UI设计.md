# UI 设计说明（第三阶段重设计，2026-11-17）

第一版照 Persona 3–5 做了深色斜切风，Cora 看了说太黑、太浓、也太像 Persona，所以改成现在这版：**偏淡的糖果色“贴纸”感**。从参考里只留了节奏感（轻微倾斜、错位影子、依次弹入、斜向擦除转场），不用它标志性的深色大色块、硬切角和英文描边大字。

样式都在 `css/phase3.css`（最后加载，覆盖前两阶段）。框体全部用 CSS 画，没有新图片。

## 设计语言

| 手法 | 用在哪 |
| --- | --- |
| 奶油底；蜜桃、粉、薄荷、天蓝、奶黄当色块；深蓝只用在文字上 | 全部 |
| 圆角卡片 + 白边 + 粉彩错位影子（像贴纸） | 对话框、选项、按钮、日程、结算、面板标题 |
| 轻微倾斜（-2°～-4°） | 名牌、日期块、面板标题、选项 |
| 网点、斜条纹浅底纹 | 对话框、日程板、浮层背景 |
| 斜向擦除转场 | 换场（蜜桃、粉两条斜色带对扫） |

## 各画面

- **HUD**：顶部一条浅色带＋蜜桃色细线；左上角白色日期卡（学期小字、周数大字）；数值是白色圆角小卡（每个影子颜色不同）；手机／存档／设置是三个大号糖果色按钮，横着排。
- **对话框**：奶油色圆角框＋粉色影子；名牌是橙色圆角标签斜贴在左上角；主角头像是蜜桃到粉的斜切框（平行四边形），在框里左边、上下居中。
- **选项**：画面轻轻蒙一层白，选项是白色圆角贴纸条，影子粉／薄荷／天蓝轮换，悬停变奶黄。
- **标题**：右侧一张白色斜条纹卡片（盖住背景图自带的三条色带），菜单大字＋英文小字，悬停时出现奶黄色底。
- **日程**：奶油色日程板，五天是白色圆角条，左边的日期标签五种颜色；选中的那天是奶黄底＋橙框。
- **浮层**（设置、存档、记录、回忆、手机）：浅色斜条纹背景；右上角是白色“✕ 关闭”大按钮。设置五行加 API 一屏放得下，不用滚动。
- **小红书**：有配图的帖子用背景图当封面；没有配图的（API 生成的、玩家自己发的）用标题或 AI 给的 `cover_text` 自动做文字封面：浅色底、大引号、开头两个字划荧光笔，五种配色按标题轮换。

## 想要的素材（有了会更好，没有也能用）

1. **可以打包进游戏的圆润粗体中文字体**（最重要）。现在用的是系统字体，最粗只到苹方 Semibold／冬青黑体 W6。糖果风配圆体会更可爱，建议找一款可商用、能打包的圆体（比如思源柔黑体／Resource Han Rounded，SIL OFL）。上 Steam 前本来也要换字体（见 README）。
2. **标题背景的干净版**：现在的 `title.jpg` 右边画了三条色带，新设计用一张浅色卡片盖住了。如果有一版右边没有色带的，卡片可以做得更透，露出更多画面。
3. **（可选）设置面板的行底图**：`settings_panel.png` 是深蓝描边的小票，和新的淡色风格比稍微重一点。如果有一版浅色描边的，换上会更统一。
