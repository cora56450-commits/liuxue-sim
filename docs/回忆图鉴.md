## 一、三个分页

| 分页 | 放什么 | 怎么解锁 |

## 二、事件分页的分类（左边一列标签）

1. **学长**、**Ollie**、**Ploy**、**Kieran**：各自的相识、阶段事件、心动／推进／过去、小事件、扩写、地点偶遇、动心视角、告白、考验、交往后、吃醋、同居、亲密关系、拥抱、接吻、分手、生日。
   - 每个人里面再按**阶段**排：相识 → 熟人 → 暧昧 → 交往 → 结局。每一格显示事件名＋缩略图（用那段第一张背景）＋演到的大学年份。
2. **朋友**：12 个朋友各一组（友情事件、中段、挚友、偶遇）。
3. **NPC 与路人**：老师、房东、Dave、路人、周末地点小剧情。
4. **主线**：固定事件（按大一／大二／大三、周数排）、年度大场面、春节、生日。
5. **修罗场**：鱼塘翻车、修罗场 1–8、吃醋小场景。

- 没解锁的格子显示剪影和"???"，**但显示事件名的第一个字**（让玩家知道"这里还有东西"）。
- 每个人的组右上角显示完成度：`23 / 41`。
- 重看：从头演到尾，**不改数值、不改标记**，选项可以选（选哪个看哪个分支，演完回到图鉴）。有【如果：xx】条件的分支，按"第一次演的时候的条件"演；没演过的分支不显示。
