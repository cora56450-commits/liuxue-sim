# 词条表（策划，2026-11-17）

给没留过学的玩家看的小便签。规则：

- 剧情、选项、手机消息里，某个词条**第一次出现**时加下划线，点一下（手柄选中按确认）弹出一张小便签；看过一次以后，后面再出现就不划线了。按存档分别记。
- 便签样式跟车站标识风走：一张米白小卡，左上角一块墨蓝小牌写“INFO 问讯处”，下面是词条名（中英）和两三行解释。点空白处或再按一次键关掉，不打断对话。
- 手机里加一个“便签本”App，按首字母列出已经看过的词条，可以随时翻；全部收集齐有一个小小的成就。
- 匹配按下面“触发词”一栏，大小写不敏感；同一个词条有几种写法的，任意一种第一次出现都算。
- 解释用主角的口吻，轻吐槽，但信息要准。涉及政策的（签证、押金）只说大概，不写具体年限和金额，避免过时。
