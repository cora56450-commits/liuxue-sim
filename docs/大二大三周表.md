# 大二、大三周表（2026-11-18，Cora 定：每年约 24 周，按周走）

替换 `大二大三关键周.md` 里"关键周＋span 一次结算"的做法。大二、大三和大一一样一周一周过：工作日排日程 → 周中插播（有的话）→ 周报 → 周末地图。原来的关键周事件（y2_move_in 等）id 不变，放进对应的周。

## 一、结构

每年 24 周：

| 周 | 学期 | 说明 |
|---|---|---|
| 1–10 | 秋季学期 | 第 6 周 reading week |
| 11 | 圣诞假 | 压成 1 周，沿用大一 term_end 的四选一结构 |
| 12–20 | 春季学期 | |
| 21 | 复活节假 | 压成 1 周 |
| 22–24 | 夏季学期 | 复习、考试、收尾 |

- 比大一少 4 周：没有迎新周，第三学期压短。
- 不是每周都有固定事件。表里写"池子周"的，那周只走公共池（周末地点小剧情、周中事件、人物阶段事件、偶遇），三年共用，按年级换台词。
- 大二大三的公共池要加"年级变体"：同一个地点、同一个人，大二大三的台词不一样（例：大一在中超被陈建国问"新来的吧"，大二他直接问"还是老干妈两瓶？"）。
