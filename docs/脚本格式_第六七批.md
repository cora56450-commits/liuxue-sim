# 剧本转脚本：第六、七批新格式（coding 用）

先读 `docs/脚本格式_第五批.md`（基础写法、手机段、限时选项、小游戏、物品、随机挑人、登记表），这里只写第六、七批新加的。转完跑：

```
node tools/validate_events.js data/events/你的文件.js
```

## 一、通用规矩（和第五批一样，再强调几条）

- 正文照抄，不改写、不删句子；剧本没写反应的选项，写进文件末尾 `// 缺反应：…`，不要自己编。
- 只改分给你的文件。要引擎支持的东西写进文件末尾 `// 给引擎：…`。
- 连锁店名一律按 `../02_剧本/剧本_日常生活池.md` 第〇节改名表（Tesko、Lidel、星八克、嘻茶、M&Z……）。
- Roger Stevens 楼 → Henderson 楼。
- 条件里新能用的变量（引擎这批加）：
  - `家境 == '拮据' | '中产' | '富裕'`
  - `英文名`（字符串，没起是空串；条件写 `英文名 != ''`），文本变量 `{英文名}` `{叫我}`
  - `告白后('local')`：告白（`confessed_local`）之后过了几周，没告白是 -1
  - `见过面('local')`：这周（约会、周末地点碰到、旅行）见过面
  - `交往中('local')`、`考验('local')`（1 过、-1 没过、0 还没演）照旧
  - `阶段('local')`：0 陌生 1 熟人 2 心动 3 暧昧 4 交往（按好感线 20/40/60/80，交往看 `confessed_`）
- 文本变量：`{名字}` `{英文名}` `{叫我}`（这个人叫你什么）`{名字的错误念法}` `{离谱念法}`（同 `{名字错法}`）。

## 二、视角段【视角：某人】……【视角结束】

```js
{ pov: "local", steps: [
  { say: "回家的路上，他一直在小声念她的名字。" },
  { say: "…", name: "local", tr: "…" },          // 他说出口的话照常英文＋tr
] }
```

- 画面变暖灰、对话框换他的名牌色、左上角“—— Ollie ——”，引擎做。
- 设置里关掉“显示攻略对象视角”时，整段跳过。所以视角段里**不要放 fx、标记**，要设的东西放在 `pov` 外面。

## 三、动心视角段的“原因那一行”

```js
{ why: { who: "senior", n: 1, rows: [
  { key: "refused", if: "标记('refused_senior') || 家境 == '拮据'", text: "她第二天要转钱给他。……" },
  { key: "rich",    if: "家境 == '富裕'", text: "…" },
  { key: "tag_saver", if: "标签('省钱达人')", text: "…" },
], def: "她叫他“学长”，不叫“Leo 哥”。……" } }
```

- 引擎从上往下找第一条满足的、而且这个人前面几段**没用过同一个 key** 的；都不满足用 `def`。设 `why_{who}_{n} = key`。
- 同一个 tag 在三段里 key 要写成一样的（比如三段都用 `tag_学霸底子`），引擎才知道“用过了”。
- `why` 步骤可以放在 `pov` 里面（它只显示一句旁白，标记引擎在外面也会设，关掉视角时照样记）。
- 登记：`DATA.heartPov = { senior: ["pov_senior_1", "pov_senior_2", "pov_senior_3"], … }`（第 1 段心动后、第 2 段推进后、第 3 段告白前一周）。

## 四、攻略对象的新一类事件（都登记进 `DATA.loveEvents`）

| 类 | 写法 | 说明 |
|---|---|---|
| 相识（0–39） | `{ id, who, kind: "acquaint", small: true, place?, cond: "… && !交往中('x')" }` | 好感门 39 由引擎管 |
| 没资格吃醋 | `{ id, who, kind: "jealous", small: true, cond: "好感('x') >= 20 && 好感('x') < 40 && 演过('前一段') && !交往中('x')" }` | 按链的顺序，一段一次 |
| 过渡（链的最后一段） | 同上，另加 `bridge: true`，**不写 small** | 不乘 0.4，好感可以从 39 进 40 |
| 交往后小事件 | `{ id, who, kind: "dating", small: true, cond: "交往中('x') && …" }` | |
| 修罗场 | `{ id, who: "A的id", kind: "cross", cond: "…" }` | 扣分不受阶段门限制，引擎认 `kind: "cross"` |
| 同居 | `{ id, who, kind: "cohab", cond: "…" }` | 见第八节 |

- 有 `place` 的：周末去那个地点时演（算“见过面”）；没 `place` 的：周开头演。
- 一周最多一段攻略线事件，引擎排队。

## 五、地点偶遇攻略对象（`剧本_地点偶遇攻略对象.md`）

```js
DATA.loveEncounters.push({ id: "enc_campus_senior_1", who: "senior", place: "campus", stage: "acquaint" });   // acquaint 相识(<40) | flirt 暧昧(40–79 没交往) | dating 交往中
```

- 正文写成 `DATA.events[id]`。可以再加 `cond`（季节、学年、tag……）。
- 引擎：和地点小剧情池一起抽，权重 ×1.5；同人同地同阶段只演一次；演了算“见过面”；好感按小事件算。

## 六、日常生活池：地点里的“二级菜单”

```js
DATA.placeActs = DATA.placeActs || {};
DATA.placeActs.city_centre = [
  { id: "cc_newdrink", name: "喝新品", open: ["pm", "eve"], fx: { money: -6, energy: 4 },
    texts: [ { id: "cc_starbuck_1", if: "季节 == '秋'" }, { id: "cc_starbuck_2" } ], first: "cc_newdrink_first", order: "seq" },
];
```

- 地点 id：`city_centre`（新地点“市中心”，下午、晚上）、`supermarket`（点进去选七家超市，见下）、`station`（出城里多“一个人去附近小城”）、`dorm_room`（住处：学做菜、点外卖）、`brunch`。
- 一条活动：`name` 菜单上的字；`open` 时段；`fx` 去一次的数值；`texts` 一串事件 id（每个可带 `if`），`order: "seq"` 按顺序、`"rand"` 随机；`first` 第一次去演的那段（可不写）；`cond` 活动出现的条件；`once: true` 只能做一次（小城每个一次）；`cost` 占几个时段（小城写 `days: 1`）。
- 超市七家：`DATA.shops = [ { id: "tesko", name: "Tesko（特易）", price: 1.0, open: ["am","pm","eve"], texts: [...], first: "…" }, … ]`，价格系数照剧本第八节。
- 外卖：`DATA.takeaway = [ { id: "ubar", name: "Ubar Eats", money: -14, energy: 6, texts: [...] }, … ]`；小麻烦那几句 `DATA.takeawayLines = [ "…" ]`。
- 一句话的文本（不是一整段剧情的）可以直接写 `texts: [ { say: "……" } ]`。
- 这些都不加好感，不进阶段门。

## 七、旅行（`docs/旅行系统.md`、`剧本_旅行.md`）

- 专属事件 id：`trip_{区}_{人}`，区：`west` `south` `north` `east` `africa` `aus` `america` `sea`；人：`senior` `local` `groupmate` `otaku`。Ploy 暧昧/交往两版：在事件里 `{ if: "交往中('groupmate')", then: [...], else: [...] }`。
- 通用：`trip_{区}_g1`、`trip_{区}_g2`；`trip_money_talk`（通用-1 钱怎么算）。
- 签证小事件：`visa_schengen`、`visa_ireland`、`visa_us`、`visa_au`、`visa_jp`。
- 日本：`trip_japan_0`（出发前）、`trip_japan_1`～`trip_japan_3`（连演）。
- 背景：`trip_west` … `trip_sea`、`trip_japan`（没有的引擎会顶）。
- 登记：`DATA.trips.push({ id, region, who })`（通用的 `who: null`）。区、城市、花费、签证这些系统数据引擎写在 `data/travel_map.js`，你不用写。

## 八、同居

- 事件 id：`cohab_{人}_1`（提议）、`cohab_{人}_2`（搬进去那天）、`cohab_{人}_3`（第一次小矛盾）。
- 时间按 `docs/恋爱节奏调整_1118.md` 第四节：**大三第 4–8 周提议，大三第 12 周搬，小矛盾在搬进去以后**。Ollie 的提议接在考验 `trial_local` 后面。
- 选了同居设 `cohab_{人}`；背景 `cohab_senior` `cohab_local` `cohab_otaku`（Ploy 用 `ploy_flat`），引擎负责大三“住处”换背景。

## 九、吃醋（交往中）

- 事件 id：`jealous_{人}`（每人一段，四段：学长算账、Ollie cool cool cool、Ploy 发动态、Kieran 去健身房）。里面的 `{B}` 是被撞见的那个人：登记 `DATA.jealousy = { senior: { id: "jealous_senior" }, … }`，引擎触发时把 B 填进 `S.pick.B`。
- 触发引擎管（和 A 交往中，上周末单独见了好感≥40 的 B）。

## 十、修罗场的两个特殊数值

- `fx: { flag_fishpond_honest: 1 }`：鱼塘判定读它（翻车概率减半）。
- `fx: { affcap_local: 59 }`：这个人好感以后最多 59（`affcap_{B}` 也行，B 是 pick 的人）。

## 十一、铺垫

- 一句话铺垫（大二大三）：照大一的 `DATA.foreshadow` 写，多一个 `year: 2`：
  `{ year: 2, week: 2, kind: "msg", from: "房子群", text: "…" }`；`kind`：mail／msg／say／toast。
- 小场景（去对应地点时优先演，没去用一句旁白）：
  `DATA.scenelets.push({ id, year: 2, week: 11, place: "dorm_room", cond: "…", fallback: "没去时的一句旁白" })`。
- 手机消息类：用第五批的周中插播 `DATA.midweek`（prio: 1，写 year、week、day）。

## 十二、Ploy 的 Instagram

- `DATA.momentsPool.groupmate = [ { text, tr, img, stage, when?, hook?, cmt?, reply?, story?, withMe? } ]`，照 `剧本_Ploy的Instagram.md` 第三节。`stage`：0–4（同 `阶段()`）或数组；`when`：条件；`hook`：条件满足那周一定发；`cmt`：剧本写的评论区（`[{ who, text, tr }]`）；`reply`：你评论以后她回的那句；`story: true` 是快拍；`withMe: true` 是“有你的照片”（出“转发到我的动态”按钮）。
- 别人的 Ins：`DATA.momentsPool.local`、`DATA.momentsPool.otaku_alt`（小号）同样写法，`platform: "ins"` 引擎按人自动给。

## 十三、攻略对象的事实卡和生日

- `DATA.facts = { senior: ["…", "…", "不能编的：…"], local: [...], … }`（`data/facts.js`）。
- `DATA.aiGuard = { names: [...白名单...], promises: [...承诺词...] }`（`data/ai_guard.js`）。
- 玩家给他们过生日：`DATA.theirBirthday = { senior: { main: "tbd_senior", dating: "tbd_senior_dating", minAff: 40 }, … }`。

## 十四、英文名的选项

- 有英文名才出的选项：`{ text: "“{英文名}。”", if: "英文名 != ''", then: [...] }`。
- 设老师叫什么：`fx: { flag_teachers_en: 1 }`；Sophie 杯子写英文名：`flag_sophie_en: 1`。
