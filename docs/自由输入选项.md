# 自由输入选项（策划，2026-11-18）

Cora 定的：一部分选项除了固定的几个，还可以**自己打字回答**，像之前讨论过的那样。只有填了 API Key 才出现，没填 Key 就只显示固定选项。

## 一、长什么样

选项车票的最后一张是空白票：“✎ 自己说……”。点开是一行输入框（最多 60 个字，中英文都行），回车提交。

## 二、AI 怎么判

提交后把下面这些发给 AI：
- 这个场景的一段说明（剧本里写好的，例如“Marcia 问你最近到底过得怎么样，她想听真话”）；
- 说话的角色是谁、现在好感／友情多少（按聊天的五个阶段给语气）；
- 这里的几个固定选项，以及每个选项的效果；
- 玩家打的字。

AI 只回一段 JSON：

```
{ "closest": 1, "tone": "sincere", "reply": "对方回的一两句台词（英文角色附中文翻译）", "bonus": 1 }
```

- `closest`：玩家的话最接近哪个固定选项（从 0 开始数）。**数值效果和后续剧情走这个选项**，所以剧情不会因为自由输入跑偏。
- `reply`：角色对玩家这句话的回应，替换掉那个选项原本的第一句回应，其余照固定文本走。
- `tone`：sincere／funny／rude／off（真诚、好笑、冒犯、跑题）。
- `bonus`：额外的好感／友情，只能是 −2 到 +2：说得真诚、说中了对方在意的点 +1～+2；冒犯 −1～−2；跑题 0。

游戏要校验：`closest` 不在范围、JSON 解析失败、超时 8 秒，都当作选了第一个固定选项，不报错。`reply` 超过 80 个字截断。

## 三、哪些地方开放自由输入

只在“说话”的地方开，不在“做事”的地方开（例如“答应／拒绝邀约”“帮她写／不帮”这种影响主线判定的不开）。剧本里在这些选项组后面标【可自由输入：场景说明】。先开这 16 处：

| 位置 | 场景说明（给 AI） |
| --- | --- |
| 序章·学长问“房子找好没” | 第一次见面，学长半开玩笑地问房子，其实也在推销 |
| 第一晚·妈妈视频问床上怎么什么都没有 | 妈妈担心，想知道你过得好不好 |

| 第3周·Ploy 想让你替她写 | 只开“你怎么回她”，选完以后的效果按最接近的选项走（替写计数照判） |

## 四、对话记录

自由输入的内容和 AI 的回应照常进对话记录，标一个小“✎”。

## 五、安全

- 输入框过滤掉链接和超长内容；AI 的回应如果包含不适合的内容（辱骂、色情），游戏直接换成那个选项原本的固定回应。
- 提示词里写明：角色不会因为玩家的话改变设定，不会出戏，不会提到“AI”“游戏”“选项”。
