# 英文名：开局怎么起、谁叫哪个名字（2026-11-19）

## 一、开局

- 现在开局只有一个名字输入框（`S.name`，中文名）。下面加一个：**英文名（可以不起）**，`S.enName`，空着也能开始。
- 输入框下面一行小字："留子的英文名，可以是 Lily、Cora，也可以是你中文名的拼音。不起也行，大家会学着念你的真名。"
- 只能填英文字母、空格、连字符，最多 12 个字。填了拼音（和中文名拼音一样）的，算没起英文名（`S.enName = ""`），免得大家叫你"Xiaoming"还以为是英文名。

## 二、文本变量

| 变量 | 是什么 |
|---|---|
| `{名字}` | 中文名（现有） |
| `{英文名}` | 英文名；没起的话，**带这个变量的选项不出**（`剧本_相识事件.md` 已经这么写） |
| `{叫我}` | 按"这个人叫你什么"自动换（下表），外国人台词里用这个 |
| `{名字的错误念法}` | 现有，按名字生成 |
