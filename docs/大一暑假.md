# 大一暑假（给编程，2026-11-17）

Cora 定的：大一暑假不压缩成一次选择，按月安排，一共四轮（六、七、八、九月），玩法和平时类似，但一轮管一个月。剧本在上一级 `剧本_固定剧情_大一全年.md`，表格以那份为准，这里只写实现要点。

## 流程

第28周 `year1_end` → 大一结算UI → `summer_start` → 四轮循环 → 大二。

每一轮：
1. 选“这个月怎么过”（一个选项，界面可以复用浓缩章节的 `focusPlans` 选择界面）
2. 按 4 周结算（自然变化、每周固定开销、tag 的每周效果都跑 4 次）
3. 演本月固定事件：`summer_{月}_{cn|uk}`，再加不分地点的 `summer_7_results`（七月出分）、`summer_9_junior`（九月老乡群）、`summer_9_house`（九月学长）
4. 手机可用

## 人在哪

- 状态 `S.summerLoc`：`uk`／`cn`。第28周以后是 `uk`。
- 第一次选国内选项：演 `summer_fly_home`（机场＋登机前消息），家里出机票。
- 九月那轮结束时在 `cn`：演 `summer_9_return_cn`，家里出机票。
- 其余换地点：机票 £400 自己出，选项上标出来。

## 自然变化

- `cn`：孤独不自然增长；不扣每周固定开销；家里不打生活费。
- `uk`：孤独每周 +3；每周固定开销照扣；六月额外短租 £300（七月起大二房子起租，房租视为已付）。

## 选项

照剧本草稿里的表：9 个选项，标了“在哪”“哪几个月”“条件”。条件不够时选项灰掉，并显示原因（例如“需要英语≥60、融入≥35”“需要申根签证”）。新标记：`cn_intern`、`uk_intern_y1`；`uk_intern_y1` 在大二暑假申实习时把融入门槛降 10。

## 补考

七月出分时年均分 <40：八月锁定在 `uk`，选项只有“复习”（学业 +5，精力 −10），月底演 `resit`。

## 出分

大一的考试分数和年度成绩放到七月出（`summer_7_results`），第28周的结算UI不显示年度成绩。
