# BGM 接线（2026-11-19，Cora 试玩：一直在放标题曲，太动感，听累了）

## 问题

`data/events/*.js` 里**一个 `bgm` 都没有写**（全剧本 0 处）。系统自动切的只有：标题、排日程、周末地图、手机、结局、ddl 周、春节周。所以**从序章开始到第一次排日程，一直放标题曲**；之后每段剧情也都沿用上一个场景的歌。

## 规则（给 coding）

1. **离开标题画面就停掉标题曲**，标题曲只在标题画面放。
2. **剧情没写 `bgm` 时，按背景自动选**（下表）。同一首歌在放就不重新开始。
3. 剧情里写了 `{ bgm: ... }` 的以剧情为准（下面第 3 节是要补写的几处）。
4. 视角段：不换歌，音量压到 60%。
5. 音量：设置里分开"音乐""音效"两个滑条（如果还没有）。
