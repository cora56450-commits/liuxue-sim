# 字体（2026-11-17 下载）

| 文件 | 字体 | 用在哪 | 授权 | 来源 |
| --- | --- | --- | --- | --- |
| `SourceHanSansSC-Heavy.otf` | 思源黑体 简中 Heavy | 标题、大字、按钮 | SIL Open Font License 1.1（`SourceHanSans-LICENSE.txt`） | https://github.com/adobe-fonts/source-han-sans （release 分支 OTF/SimplifiedChinese） |
| `SourceHanSansSC-Medium.otf` | 思源黑体 简中 Medium | 正文、对话 | 同上 | 同上 |
| `BarlowCondensed-Medium.ttf` `-SemiBold.ttf` `-Bold.ttf` | Barlow Condensed | 英文小字、数字（周数、钱、读数） | SIL Open Font License 1.1（`BarlowCondensed-OFL.txt`） | https://github.com/google/fonts/tree/main/ofl/barlowcondensed |

SIL OFL：可以商用，可以打包进游戏一起卖；不能单独把字体文件拿出来卖；改了字体文件的话不能再用原来的字体名。上 Steam 时在制作名单里写一行字体名和授权就够了。

注意：思源黑体每个字重 17MB，网页版第一次打开会慢一点。之后可以按游戏里用到的字做子集（裁成常用字），能缩到几 MB。
