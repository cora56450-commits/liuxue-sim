# 音效来源

全部来自 Pixabay 音效区（可以商用、不用署名）。Cora 2026-11-17 下载，原文件在项目根目录 `点击音效/`。具体每个的作者和链接待 Cora 补（候选见 `docs/音效试听清单.md`）。

截过的（编程用 macOS afconvert 截段、转 AAC .m4a，开头 10ms 淡入、结尾 150ms 淡出）：

| 游戏里 | 原文件 | 截取 |
| --- | --- | --- |
| flap.m4a | 周数翻页只要9-15秒左右或者更短.mp3 | 9.45–10.9 秒（翻牌声从 9.5 秒开始） |
| fire_alarm.m4a | 火警.mp3 | 0.6–8.5 秒 |
| heartbeat.m4a | 告白:紧张:心跳.mp3 | 0–5.5 秒 |
| airport_chime.m4a | 机场提示音.mp3 | 1.4–7.6 秒（第一遍提示音） |
| ticket_punch.m4a | 开始这一周:答应邀约.mp3 | 0.6–1.6 秒 |
| paper_tear.m4a | 撕票转场.mp3 | 0.3–1.6 秒 |
| amb_pub.m4a | 环境音 pub.mp3 | 5–125 秒，单声道 64k，循环 |
| amb_rain.m4a | 环境音 雨.mp3 | 2–122 秒，单声道 64k，循环 |
| amb_station.m4a | 背景音 火车站.mp3 | 5–125 秒，单声道 64k，循环 |

原样复制的：ui_click（点击）、ui_popup（便签邀约弹出）、whoosh（到站广播滑入）、station_chime（下一站广播）、page_turn（翻记录:便签）、stamp（结局盖章）、phone_msg（收到消息）、phone_send（发送消息）、camera（拍照:发小红书）、knock（敲门）、fireworks（篝火会）、microwave（微波炉）、typing（赶ddl:键盘敲击）、cash（剁手:花钱）、coin（兑硬币）、glass_clink（干杯）、train_door（火车到站:开关门）。

还没有的：kettle（烧水壶）。
